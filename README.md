# 달지기 (Moon Keeper)

지구로 떨어지는 소행성을 달로 막는 궤도 디펜스 게임

2023184027 게임공학과 이현렬, 2D 게임 프로그래밍 텀프로젝트

## 게임 개요

- 장르: 궤도 디펜스 + 증강 선택형 성장
- 개발: Python, pico2d, 800 × 600 창 모드
- 한 판: 약 15분, 웨이브 10개

## 조작

| 입력 | 하는 일 |
|---|---|
| → | 가속, 궤도가 넓어짐 |
| ← | 감속, 궤도가 좁아짐 |
| Q W E | 스킬 사용 |
| 1 2 3 / 클릭 | 증강 카드 고르기 |
| ESC | 일시정지 |

## 실행 방법

```
pip install pico2d
python main.py
```
